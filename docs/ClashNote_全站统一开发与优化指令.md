# Clash Note 全站统一开发与优化总指令（Claude Code）

你现在是 Clash Note 项目的技术负责人、全栈前端工程师、UI/UX 设计师、中文技术编辑、SEO 工程师和测试工程师。请直接检查当前工作目录中的项目文件、历史资料与品牌 Markdown，完成全站升级。**这是对整个 Clash Note 项目的最终整合要求，不是只做一张首页效果图。**

## 0. 优先级和工作方式

1. **先读项目再改代码**：识别 Hexo、当前主题版本、项目目录、文章、路由、主题配置、构建及部署方式。检查是否包含 `ClashNote_ClaudeCode_项目包/CLAUDE_CODE_完整建站指令.md`、`数据审查说明.md` 与 `品牌资料/` 目录；如果文件在其他位置，搜索同名文件。全部读完再实施。此前指令中关于 17 家品牌数据、Clash 兼容性、优惠码、来源及实测真实性的要求继续有效。
2. **本指令在视觉设计方面覆盖先前的“Stellar 深蓝黑文档风”要求**：用户不喜欢 Stellar 默认文档页面，不要做出左侧窄菜单 + 大片普通白色正文的传统知识库外观。新设计定位为“高级极简科技博客 + 产品化知识中心”，清爽、克制、有品牌感，并且好阅读。内容及数据要求不受此覆盖。
3. **保留已完成成果**：先创建 Git 检查点或可恢复备份，先列现有页面与目录，不删除已有文章、图片、品牌资料、域名配置和有效的内部链接。优先维持 Hexo。主题优先考虑与当前 Hexo 兼容的 Redefine；若当前 Stellar 已有大量内容，不盲目重建，可采用主题替换或自定义布局/样式完成相同目标。最终仅选择一条稳定方案，不要在项目里混装多个主题。
4. 尽可能自行读取项目并执行，不反复要求站长介绍已有内容。若缺少重要资料，用“待核实”并保留资料来源，绝不编造价格、速度、截图、链接、用户评价、认证和测试通过结果。不得未经授权部署生产站、修改 Cloudflare、DNS、GitHub 远程仓库或公开私密凭据。
5. 全站正文、导航、标签、表单提示和错误信息使用**简体中文**。

## 2. 全站统一视觉系统（强制）

使用高级、干净、浅色科技风（Premium Minimal Tech）。

- 默认浅色：页面背景 `#F7F9FC`，主卡片 `#FFFFFF`，文字 `#17243A`，次级文字 `#60708A`，主题蓝 `#4169E1`，弱边框 `#E5EAF2`；冰蓝/浅紫渐变仅在 Hero 局部点缀。
- 支持深色切换，但默认不使用大片深蓝黑赛博背景。深色模式独立做颜色对比度检查。
- 顶部统一悬浮感导航栏，窄边框、白色或浅磨砂背景、合理留白。Logo 使用原创简洁符号，不能复制任何官方软件商标。

- 容器宽度桌面约 1160–1280px；正文约 740–820px；正文 16–18px、行高 1.7–1.85，重视易读性。卡片圆角 14–20px，柔和阴影、1px 细边框和适度悬浮反馈。统一 8px 间距体系。

- 不要过多玻璃拟态、发光描边、渐变色、动画、彩色徽章；克制才有高级感。
- 移动端适配 320、375、390、768px，桌面 1024、1440px；底部不横向溢出，卡片不挤压，表格可横向滚动或变为卡片，导航变为抽屉。
- 所有真实交互必须有明确点击反馈、加载、错误与空状态；不做假按钮。
- 不得直接复刻其他博客的受保护图片、Logo、文字或截图。
